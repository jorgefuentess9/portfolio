# Portfolio Personal — Jorge Fuentes Aguilar

Bienvenido a mi portfolio personal como estudiante de **Desarrollo de Aplicaciones Multiplataforma (DAM)**. 

Un espacio con diseño minimalista en modo oscuro estilo terminal/dev, enfocado en mostrar mis proyectos, habilidades técnicas en desarrollo de software, gestión de bases de datos e interfaces web.

---

## Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (ES6+).
- **Formularios:** Integración con Formspree.
- **Despliegue & Hosting:** Vercel / GitHub Pages.
- **Control de Versiones:** Git & GitHub.
